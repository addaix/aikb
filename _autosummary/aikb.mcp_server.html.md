# aikb.mcp_server

MCP server exposing knowledge base CRUD as tools.

Requires `pip install aikb[mcp]`.

Run with:

```default
python -m aikb.mcp_server
```

| [`create_server`](#aikb.mcp_server.create_server)()   | Create and return the FastMCP server instance.   |
